# Test Checklist — Minimal Ink Pen Drawing V1

每次测试完成后逐项检查。可按“通过 / 需调整 / 不适用”记录。

## A. 主体识别

- [ ] 主体仍然清楚可辨。
- [ ] 主要人物或动物数量正确。
- [ ] 姿态、脸部朝向和主体之间的关系基本保留。
- [ ] 独特特征没有被误删。

## B. 自动删减

- [ ] 无关背景已删除或大幅简化。
- [ ] 重复纹理、反光、噪点和装饰没有被大量描绘。
- [ ] 保留下来的辅助元素确实有助于理解画面。

## C. 线条风格

- [ ] 线条为清晰实黑，而不是灰色素描线。
- [ ] 线条偏细，不显得粗重。
- [ ] 内部线条数量少，没有密集排线或交叉排线。
- [ ] 线条有轻微手绘感，但整体不凌乱。

## D. 画面与背景

- [ ] 背景干净、偏暖白。
- [ ] 有足够留白，主体视觉重心清楚。
- [ ] 画面不是彩色涂鸦或贴纸拼贴风格。

## E. 通过标准

若主体辨识、关键特征、背景删减和线条风格均满足要求，可判定通过。若只在一个方面不满足，优先做针对性修正，不要推翻整个风格。

## 常见修正方向

- 线条太粗：整体视觉线宽降低到上一版约 75%。
- 线条太密：删除内部纹理和重复短线，不要靠变灰解决。
- 主体不像：恢复轮廓、姿态、表情和标志性特征。
- 背景太复杂：移除背景，只保留主体和必要的关系线。
- 过于规整：增加轻微的自然线条变化，避免过度修饰。
