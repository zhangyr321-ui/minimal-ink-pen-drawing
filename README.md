# Minimal Ink Pen Drawing Skill

将照片转换为**极简黑色钢笔手绘线稿**的 Agent Skill。它会优先识别重要主体，删掉不必要背景和重复纹理，再用细而实黑、略带手绘不规则感的线条重新概括画面。

> V1 只包含黑白极简钢笔画，**不包含彩色涂鸦模式**。

## 风格目标

- 细而清晰的实黑线条，不用粗重漫画描边
- 暖白底色与充足留白
- 主体优先，背景自动删减
- 保留姿态、神态、构图和独特特征
- 内部细节少，不做素描排线或写实阴影
- 自然、轻盈、略带拙趣的手帐插画感

## 使用方法

### 在支持 Agent Skills 的工具中

1. 下载或克隆本仓库。
2. 将整个 `minimal-ink-pen-drawing` 文件夹放入所用工具支持的 Skills 目录。
3. 上传一张照片，并提出“把这张照片转成极简黑色钢笔手绘线稿”等请求。
4. 确认该工具能够调用图像生成或图像编辑模型；Skill 本身是操作说明，不自带图像模型。

不同工具的 Skills 目录和加载方式可能不同，请以该工具的官方文档为准。

### 在 ChatGPT 中试用

GitHub 仓库链接本身不会自动让普通 ChatGPT 对话加载 Skill。可以在支持图像生成的 ChatGPT 对话中上传照片，并把 `SKILL.md` 中的规则作为指令使用；也可以在支持文件与项目指令的工作区中加入该文件。具体能力取决于当前 ChatGPT 功能与设置。

## 关键取舍原则

内容保留优先级：

1. 主体辨识度
2. 姿态与构图
3. 独特特征
4. 必要环境信息
5. 表面纹理

例如：树冠不逐片描叶，动物不逐根描毛，人物衣服不逐个描花纹；但人物数量、神态、发型、关键配饰和有趣的小特征应尽量保留。

## 当前限制

- 这是一个以自然语言规则为核心的 Skill，不是独立图像处理程序。
- 实际结果受所用 Agent、图像模型和图像编辑能力影响。
- 不同模型可能对主体取舍、线条粗细和人物细节有不同表现，需要根据测试结果迭代。
- 本仓库不包含用户测试照片，以免未经许可公开个人图片。
